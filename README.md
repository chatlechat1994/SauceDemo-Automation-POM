#  SauceDemo UI Automation Framework (POM)

A professional UI automation suite demonstrating the **Page Object Model (POM)** design pattern for scalable testing.

##  Skills Demonstrated
* **Framework Design**: Structured separation of page elements (`pages/`) and test logic (`tests/`).
* **Clean Code**: Implementation of `.gitignore` to keep the repository free of `__pycache__` and junk files.
* **Tools**: Python, Selenium WebDriver, and Pytest.

##  Project Architecture
* **pages/**: Contains locators and interaction methods for the Login and Inventory pages.
* **tests/**: Contains the end-to-end purchase flow test scripts.
* **.gitignore**: Ensures only necessary source code is tracked.

##  Execution
1. Install dependencies: `pip install selenium pytest`
2. Run tests: `pytest`
